女性size LoRA用プロンプト候補 v2

使い方
- 各案の NORMAL / SMALL / LARGE を、そのまま1本ずつ CLIPTextEncode に貼り付ける。共通文の継ぎ足しは不要。
- 最初は size LoRA を含む追加LoRAをすべて外し（darkbrush 0）、同一seed・同一生成設定で3状態を比較する。既存例と比べる必要がある場合だけ darkbrush 0.8 を別系列として試す。
- 良さそうな案だけを2〜3 seedで再確認し、さらに人物の左右を入れ替えたプロンプトでも挙動を見る。
- 各画像について、人物数、女性の見かけの身長比、男性の画面内身長、男性まで縮小・拡大したか、全身の欠け、二人の距離、カメラ構図の変化を記録する。
- これらは未検証候補であり、2人固定、3人化防止、正確な寸法、男性サイズ固定を保証しない。10案すべてを学習データへ自動採用せず、RAW結果を見て有効な2〜3案に絞る。
- 全案とも成人男女、着衣、通常の成人頭身、同じ床面・同じカメラ距離、全身表示を明記している。比率は NORMAL 1.0、SMALL 0.5、LARGE 2.0 に統一した。
