# Third-party sources

`krea2_slider_node/model.py` is adapted from the Krea AI Krea2 official inference code, commit `db3984fbc6e13b34c0064990fc2d95ac64d00058`, licensed under Apache-2.0. The license is retained in `licenses/Krea2-Apache-2.0.txt`. Modifications remove forced cuDNN/compilation, add portable SDPA, checkpointing and a latent interface. Model weights have their own license and are not distributed here.

ConvRot's regular Hadamard convention and frozen input-gradient formulation follow Musubi Tuner `4e7c7149249e7715e9168920feb4c420423abba7` and its Apache-2.0 Comfy Kitchen-derived kernels. Upstream notices: Copyright (c) 2025 NVIDIA CORPORATION & AFFILIATES. All rights reserved. Copyright (c) 2025 Comfy Org. This implementation uses eager PyTorch operations; it does not include the upstream Triton kernels. Apache-2.0 license text is retained in `licenses/Krea2-Apache-2.0.txt`.

The Slider objective is based on the Concept Sliders method (Gandikota et al., ECCV 2024) and the local Anima Slider behavior, adapted to Krea2 flow velocity. No model weights or third-party datasets are bundled.

`krea2_slider_node/region_masks.py` and `web/region_mask_geometry.js` adapt the rectangular mask rasterization, normalization, movement, corner resizing, and hit selection from D2 Create Masks in [da2el-ai/D2-nodes-ComfyUI](https://github.com/da2el-ai/D2-nodes-ComfyUI), commit `0d967672ef72fcc92fe8d915fd4f20c448134aa3`. Copyright (c) 2023 Shingo.T; MIT license retained in `licenses/D2-MIT.txt`. Modifications use two fixed V3 MASK outputs, left/right defaults, strict validation, and a separate DOM canvas editor. D2's other nodes, upload services, and shared dependency modules are not bundled.

The Krea2 regional attention work is adapted from [januspluto/ComfyUI-Krea2-Regional](https://github.com/januspluto/ComfyUI-Krea2-Regional), commit `307081f2b954d9f5e683dadafdb53ca971ebdbfd`, licensed under MIT. The upstream license is retained verbatim in `licenses/Krea2-Regional-MIT.txt`, including its original `Copyright (c) 2026 YOUR_NAME` notice. The adapted scope is the single-pass Krea2 text/image attention routing, mask-to-image-token mapping, ComfyUI diffusion-model wrapper integration, and the activation-delta approach for future token-routed LoRA support. This project uses its own node IDs, validation, background ownership rules, runtime state handling, and tests. The upstream Builder UI, JavaScript, server routes, captioning, Detailer, adaptive masks, region lock, LoKr support, and workflow assets are not included.
