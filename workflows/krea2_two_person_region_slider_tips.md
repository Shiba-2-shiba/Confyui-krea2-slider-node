# 2人構図の領域Slider：マスクとプロンプトの使い方

[ワークフロー](krea2_two_person_region_slider.json)は、成人女性を左、成人男性を右に配置し、左の条件にだけSlider LoRAのHookを付ける比較用テンプレートです。矩形マスクは生成位置を選ぶもので、人物の検出や画素単位の隔離はしません。

## 最初の比較

1. `Krea2 Region Masks`を初期値の左右半分、全高に戻します。マスクの`width`・`height`と`EmptySD3LatentImage`のサイズを同じにします。
2. 胸サイズだけを見るときは胸SliderのHookを有効にし、aging Hookの`strength_model=0`にします。両Hookに有効なLoRAファイルを選択してください。未使用Hookを削除する場合は、残すHookを女性側の`hooks`入力へ直接つなぎます。成人の加齢を見るときはaging Sliderだけを有効にします。deaging Sliderは幼児への変化を学習しているため、胸サイズ評価とは分けます。
3. 同じモデル、prompt、解像度、seed、sampler、steps、CFGで、対象Hookの`strength_model=0`を基準として`1`、`2`、必要なら`3`を順に比較します。高速化LoRAなどを使う場合も、全画像で同じ設定に固定します。
4. 左の胸部または顔・首・手の変化と、右の男性の変化を別々に見ます。右が画素単位で同一になる保証はありません。

`Cond Pair Set Props`の`strength`は**LoRA強度ではなくマスク付き条件の重み**です。左右が重ならず画面全体を覆う構成では、値を`1`から`2`にしても正規化で打ち消され、画像が変わらないことがあります。Sliderの強さは`Create Hook LoRA (MO)`の`strength_model`で変更します。実際の同一seed比較では、条件の`strength`だけを`1→2`にした2枚は全画素一致し、胸Hookの`strength_model`を`0→3→5`にした画像は主に左側が変化しました。高強度では女性の顔や男性側にも差が出たため、局所性は画像で確認してください。

## マスクを変えるとき

- `mask_1`は左、`mask_2`は右です。矩形内が1、外が0です。左右を入れ替えるとHookの対象も変わります。
- まず左右半分・全高で構図を安定させます。頭、胸、手、服の輪郭を矩形の境界で切らないでください。上端を下げた比較画像では、マスク境界を挟んで成人と幼児の顔が重なりました。
- マスクを小さくしても、人物が箱の中に収まるわけではありません。現在の`set_cond_area=default`は全画像の潜在状態から予測した結果にマスクを掛けます。小さい矩形に人物全体の文章を与えると、顔の見切れ、体の継ぎ目、人物の重複が起こり得ます。
- `Cond Pair Set Default Combine`の`DEFAULT`は**未マスク部分だけ**に効きます。左右半分・全高の初期マスクでは、画像全体が覆われるため`DEFAULT`は実質使われません。このテンプレートでは未マスク部分に背景だけを指定しています。ただし文章は生成内容を厳密に禁止する境界ではありません。人物の一部を未マスクに出すと、欠けや継ぎ目、残像が出ることがあります。
- 解像度や縦横比を変えると、同じ正規化座標でも人物との位置関係が変わります。マスク寸法とlatent寸法を揃え、マスクプレビューと生成画像を確認してください。マスクとLoRA強度を同時に変えると、原因を分けられません。

## プロンプトのTips

- 左の領域条件には成人女性だけ、右の領域条件には成人男性だけを書きます。以前は左右どちらにも「男女2人」を書いていたため、左マスクを縮めてもHookなしの条件側に女性の記述が残っていました。人物ごとの文章に分けると、左右で人物の縮尺や位置がずれる可能性もあるため、画風、カメラ位置、フレーミング、背景、光は揃えます。
- `DEFAULT`には壁・床・照明だけを書き、男女や人数を書かないでください。前の「男女2人」のDEFAULT文章は、マスクの隙間に追加人物を誘発し得る構成でした。
- 「成人女性1人が左、成人男性1人が右」「2人の間に隙間」「頭から太ももまで」「手が見える」を具体的に書きます。衣服の色を分けると左右の取り違えを見つけやすくなります。
- 効果の比較中は`big breasts`、具体的な年齢、皺など評価対象を直接指定する語を入れず、強度だけを変えます。比較基準が変わるのを避けるためです。
- このテンプレートは実写風の生成例に合わせた文章です。画風を変える場合は左右の条件を同時に変え、基準画像を撮り直します。文章を整えても、空のlatentからの生成で人数・姿勢・境界を厳密に固定することはできません。

## マスク外に人物を残さない場合

画像`00025`から`00026`は同じseed、文章、LoRA強度で、左マスクだけを変更した比較です。`00026`の左マスクは画像座標でおよそ`x=55..441, y=329..990`です。成人女性の頭はこの上側にあり、幼児の顔との継ぎ目はマスク上端の約329pxと一致します。これはHookのLoRAが外へ直接適用された証拠ではありません。マスク外にも人物が生成され得ることと、人物の一部を残したまま全身を変えると接合が破綻することを示しています。

1回生成の[領域ワークフロー](krea2_two_person_region_slider.json)では、右条件から女性の記述を除いています。これは追加の女性を減らすための**プロンプト切り分け**であり、マスク外に女性を生成しない保証ではありません。特にdeagingのように頭・顔・体格が変わる操作では、左マスクを対象人物の頭から体まで覆う大きさにしてください。

マスク外の最終画素を固定したい場合は、別の[二段階編集ワークフロー](krea2_two_person_masked_edit_composite.json)を使います。最初に「右の男性だけ、左は空の背景」のベース画像を作り、次に左マスク内へ成人女性を生成し、`Image Composite Masked`で編集画像の左だけをベースへ貼ります。このテンプレートは胸Sliderを1つだけ選ぶ開始例です。ベース画像の左が実際に空であることを確認してください。ベースに女性が残れば、最終合成もその女性を残します。

二段階版の`denoise=0.85`は初期案です。生成可能性と人物の自然さは実機で未確認です。硬い二値マスクなら最終合成のマスク外はベース画像と同じ画素になりますが、境界の不自然さは残り得ます。対象人物の一部しか入らない小さな矩形で全身の年齢変化を成立させることはできません。

## 仕組みと限界

ComfyUIの標準HookはHookを付けたconditioningで使われ、マスクはその条件の予測を空間的に合成します。未マスクの`DEFAULT`は残りの範囲にだけ適用されます。全画像を使う生成過程とVAEの復号では、反対側に小さな変化が出る可能性があります。男性側に差があるだけではHookの直接的な漏れとは判定できません。
